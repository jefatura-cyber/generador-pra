PRIVACIDAD Y DESPLIEGUE

Separación de responsabilidades

GitHub Pages publicará solamente los archivos de la interfaz: HTML, CSS y JavaScript. No se usarán bases de datos públicas con información de menores.

Google Workspace deberá procesar los datos de Séneca, guardar las configuraciones de cada centro y generar los documentos mediante permisos autorizados.

Instalación centralizada: los docentes no necesitarán copiar el código ni la URL de una implementación. El administrador de la plataforma sí tendrá que conectar y publicar el servicio seguro una vez.

Este sitio es la interfaz preparada, no la instalación final. No se enviarán formularios ni se generarán PDF hasta integrar el servicio de Google y superar las pruebas de permisos con datos ficticios.
◈
Compromiso de privacidadEsta página pública no recopila nombres, NIE ni respuestas de estudiantes. Los enlaces introducidos solo existen en la memoria de esta pestaña del navegador; no se envían a GitHub ni se guardan como almacenamiento permanente.
◈
Una web pública no debe mostrar datos personales del alumnadoLa consulta de Séneca y la generación de PDF se realizarán exclusivamente en una aplicación Google autorizada y aislada por centro. En este borrador no se consultan ni se copian datos reales.
