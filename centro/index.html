La implementación web actualizada debe incluir la pantalla ?view=gestor. Esta URL se configura una sola vez tras implementar el proyecto en Apps Script.

Se guardan enlaces y preferencias en este navegador; no se transmiten datos del alumnado a GitHub.

¿Qué es necesario para generar PDF?GitHub Pages no puede acceder por sí solo al Drive privado del centro. El panel autenticado de Apps Script ejecuta las mismas funciones del Gestor PRA sin APIs de pago; desde aquí se le transmite el curso, la hoja, la carpeta y los niveles seleccionados.
